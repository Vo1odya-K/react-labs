# ЛР-10. Структури папок

Ці таблиці заповнюєте ви: «У яких теках лежить кошик» — по рядку для
стартової структури (§4.3) і для гібридної (§4.7), «Вибір структури» — у
§4.8. Рядок «Пакет» — лише якщо виконуєте додаткове завдання §4.10. Як
рахувати теки, описано в інструкції, §4.2, а як подати таблиці у звіті —
у §5.

## У яких теках лежить кошик

Кошик — це шість файлів: сховище, `useCart`, `AddToCartButton`,
`CartLine`, сторінка кошика й шапка з лічильником. «Тек» — у скількох теках
вони лежать, «Теки» — шляхи цих тек через кому.

| Структура              | Тек | Теки                                                                                                                               |
| ---------------------- | --- | ---------------------------------------------------------------------------------------------------------------------------------- |
| За типом файлів (§4.3) | 4   | src/store/, src/hooks/, src/components/, src/pages/                                                                                |
| Гібридна (§4.7)        | 5   | src/shared/features/cart/store/, src/shared/features/cart/hooks/, src/shared/features/cart/components/, src/routes/cart/, src/app/ |
| Пакет (§4.10)          |     |                                                                                                                                    |

## Вибір структури

Описи проєктів, з чого обирати і як пояснити вибір — в інструкції, §4.8.
«Чому»: що в проєкті важливо і чому обрана структура для цього підходить.

| Проєкт                            | Структура             | Чому                                                                                                                                                                               |
| --------------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Прототип на хакатоні           | За типом файлів       | Невеликий проєкт, обмежений час розробки. Проста структура дозволяє швидко створювати компоненти без зайвої складності.                                                            |
| 2. Блог і документація на Next.js | За маршрутами         | Більшість сторінок незалежні одна від одної. Зручно групувати файли за сторінками та маршрутами.                                                                                   |
| 3. Адмінка для бариста            | За функціональністю   | Замовлення та склад використовуються на різних сторінках. Групування за функціональністю дозволяє зберігати пов'язану бізнес-логіку разом.                                         |
| 4. Інтернет-магазин кави          | Feature-Sliced Design | Великий проєкт із багатьма функціями та декількома командами. Поділ на шари та слайси допомагає контролювати залежності й масштабувати застосунок.                                 |
| 5. Облік обладнання               | Гібридна              | Наявну структуру можна зберегти, а нові частини організовувати за маршрутами та функціональністю. Це дозволяє поступово покращувати архітектуру без повного переписування проєкту. |
